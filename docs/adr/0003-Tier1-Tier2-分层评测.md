# ADR 0003: AI 评测 Tier1/Tier2 分层设计

- **日期**: 2026-07-24
- **状态**: 已采纳

## 背景

AI/RAG 应用评测长期存在"靠感觉"（无结构化指标）和"等专家"（把专家瓶颈变成阻塞点）两个极端。需要一个让团队在专家到位前也能跑的评测体系，同时不降低标准。

## 决策

将评测指标分为两层：

- **Tier1（门禁层）**：引用覆盖率、引用忠实度、拒答正确率。三项指标不依赖领域专家，基于 RAG 的"强制引用溯源"防线可直接度量。当前就能跑，作放行门禁。
- **Tier2（专家层）**：答案正确率、检索命中率。必须领域专家标注标准答案才能评测，专家不到位前挂起、不自造标准答案。

## 后果

- 正面：Tier1 可脱离专家运行，降低评测启动门槛
- 正面：Tier2 保留专家标准，不倒逼编造"伪标准答案"（正是 T8 类风险根因）
- 正面：团队在等专家时已积累基线数据
- 代价：Tier2 指标长期缺失意味着"答案正确性"没有量化保证，需要项目层面管理此风险
