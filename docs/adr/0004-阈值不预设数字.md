# ADR 0004: 评测阈值不预设数字，先跑基线

- **日期**: 2026-07-24
- **状态**: 已采纳

## 背景

插件作为通用模板，不清楚消费方项目的业务场景和风险容忍度。拍一个"漂亮"的假阈值（如 100%）反而不真实。

## 决策

- 模板中不留默认阈值数字
- 团队先跑基线评测获取真实数据
- 再按业务风险容忍度在消费方 `project-context.md` 中定阈值

## 后果

- 正面：阈值基于真实数据而非拍脑袋
- 正面：不同项目可按自身风险容忍度调整
- 代价：新项目没有起步参考值（需在安装文档中说明"首次跑基线后定阈值"）
