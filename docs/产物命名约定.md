# 产物命名约定

本文档集中定义 delivery-flow 流水线中所有产物的标准文件名和目录结构。
所有 Skill、自动化检查器（delivery-check/trace）和 `core.py` 的 glob 模式均以此为准。

## 命名规则总览

| 规则 | 说明 | 示例 |
|------|------|------|
| **固定名** | 文件名唯一，大小写敏感，不存在变体 | `SPEC.md`、`PRD.md`、`_映射表.json` |
| **日期后缀** | `{类型}-{YYYY-MM-DD}.md`，支持同类型多份 | `客户确认记录-2026-07-30.md` |
| **固定目录** | 目录名唯一，内部文件名由生成工具决定 | `stories/`、`prototype/` |
| **内部文件** | 下划线前缀，表示系统内部文件非交付产物 | `_映射表.json`、`_飞书任务模板.json` |
| **模板文件** | 中文"模板"后缀或英文 `template`，会被 `find_first` 自动排除 | `project-context模板.md` |

## 产物清单

### 根目录产物（项目根 `/`）

| 产物 | 标准文件名 | 说明 |
|------|-----------|------|
| 项目上下文 | `project-context.md` | 固定名，含红线/阈值/验收线 |
| 需求规格（机读契约） | `SPEC.md` | 固定名，Why/Capabilities/Constraints/Non-goals/Success signal |
| PRD | `PRD.md` | 固定名 |
| UX 文档 | `UX.md` | 固定名 |
| 客户确认记录 | `客户确认记录-{YYYY-MM-DD}.md` | 日期后缀，每次签字一份 |
| 架构文档 | `AD-{n}-{简述}.md` | BMAD 约定，n 为序号 |
| 技术就绪报告 | `readiness-report.md` | 固定名 |
| 映射表 | `_映射表.json` | 固定名，下划线前缀 |
| 状态镜像 | `sprint-status.yaml` | 固定名，飞书单向拉取的只读镜像 |
| 阶段进度 | `project-progress.yaml` | 固定名，流水线宏观阶段追踪 |
| 评测报告 | `评测报告-{YYYY-MM-DD}.md` | 日期后缀 |
| 验收报告 | `验收报告-{YYYY-MM-DD}.md` | 日期后缀 |

### 目录产物

| 目录 | 标准路径 | 内部文件命名 | 说明 |
|------|---------|-------------|------|
| Story 文档 | `stories/` | `{story-id}.md` | story-id 由 BMAD 生成 |
| HTML 原型 | `prototype/` | `index.html`（及其他资源） | 整页可交互演示原型 |

### 系统/配置文件

| 文件 | 标准路径 | 说明 |
|------|---------|------|
| 项目宪法 | `项目宪法.md` | 面向人读的治理文档（可选） |
| 投影配置 | `project-context.md` | AI Agent 注入的机读版 |

## 自动排除规则

`core.py` 的 `find_first()` 函数在匹配产物时自动排除：

- 文件名含 `template`（英文，不区分大小写）
- 文件名含 `模板`（中文）
- 文件名含 `示范`（中文）

路径排除（由 SKILL.md step 3 定义）：

- 路径含 `skills/`
- 路径含 `_bmad/`
- 路径含 `.agents/`
- 路径含 `.claude/`

## glob 模式速查

以下是 `core.py` 中用于识别各产物的 glob 模式（按优先级排序）：

| 产物 | glob 模式 |
|------|----------|
| SPEC.md | 直接路径 `root / "SPEC.md"` |
| 架构文档 | `AD-*.md` → `**/AD-*.md` |
| 客户确认记录 | `*客户确认*.md` → `**/*客户确认*.md` |
| 技术就绪报告 | `*readiness*.md` → `**/*readiness*.md` → `**/*技术就绪*.md` |
| 验收报告 | `*验收报告*.md` → `**/*验收报告*.md` |
| 评测报告 | `*评测报告*.md` → `**/*评测报告*.md` |
| Story 文档 | `stories/**/*.md` → `**/*story*.md` → `**/*stories*.md` |
| 映射表 | `_映射表.json` → `**/_映射表.json` |
| 状态镜像 | 直接路径 `root / "sprint-status.yaml"` |
| 阶段进度 | 直接路径 `root / "project-progress.yaml"` |

## 注意事项

- **不要用模糊文件名**：如 `需求.md`、`文档.md`——这些会匹配多个产物，导致误判。
- **日期格式统一用 ISO**：`YYYY-MM-DD`，不用 `YYYYMMDD` 或 `YYYY.MM.DD`。
- **PRD/UX 用固定名**：不用 `PRD-v2.md` 或 `UX-终稿.md`，版本通过 git 追踪。
- **映射表和状态文件用下划线前缀**：表明是系统内部文件，不是交付产物。
