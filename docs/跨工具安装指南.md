# 跨工具安装指南

> 本指南面向**非 Claude Code** 用户（Codex / Cursor / Windsurf 等）。Claude Code 用户直接在对话中说"装 delivery-flow"即可，无需阅读本文件。

---

## 前置条件

1. **Node.js** 已安装（BMAD 安装需要 `npx`）
2. **Git** 已安装
3. **delivery-flow 已 clone 到本地**：
   ```bash
   git clone https://github.com/fredsimas782-jpg/delivery-flow.git
   ```
   记下 clone 后的本地路径，下文用 `<DF_PATH>` 表示。

---

## 按工具安装

### Codex (OpenAI)

**1. 在项目根创建 `AGENTS.md`**（如已存在则在末尾追加）：

```markdown
## delivery-flow 交付工作流

delivery-flow 已安装，技能文件位于 `<DF_PATH>/skills/`。
当需要执行交付流程时，按以下顺序读取并遵循对应 SKILL.md：
- `delivery-bootstrap` — 安装引导（首次使用）
- `delivery-onboarding` — 流程入口与角色路由
- `delivery-client-gate` — 客户签字关卡
- `delivery-feishu-sync` — 飞书任务同步
- 其余技能见 `<DF_PATH>/skills/` 目录

项目约束文件：`project-context.md`（必须存在）
阶段进度文件：`project-progress.yaml`
```

**2. 安装 BMAD**：
```bash
npx bmad-method install
```

**3. 创建 `project-context.md`**：从 `<DF_PATH>/templates/project-context模板.md` 复制到项目根，填入项目信息。

**4. 创建 `project-progress.yaml`**：从 `<DF_PATH>/templates/project-progress模板.yaml` 复制到项目根，所有阶段设为 `pending`。

### 其他工具

如果你使用的工具不在上述列表中：

1. 将 `<DF_PATH>/skills/` 路径告知你的 AI agent
2. 在项目根创建 `project-context.md`（从 `<DF_PATH>/templates/project-context模板.md` 复制）
3. 在项目根创建 `project-progress.yaml`（从 `<DF_PATH>/templates/project-progress模板.yaml` 复制）
4. 运行 `npx bmad-method install` 安装 BMAD

核心原理：delivery-flow 的所有 skill 都是 Markdown 文件，**任何能读 Markdown 的 AI agent 都能遵循这些工作流指令**。配置文件的作用只是让 AI agent 知道去哪里找这些文件。

---

## 验证安装完成

无论使用哪种工具，确认以下文件存在：

| 文件 | 状态 |
|---|---|
| `project-context.md` | ✅ 已创建并填入项目信息 |
| `project-progress.yaml` | ✅ 已创建，current_stage: requirements |
| `_bmad/` | ✅ BMAD 已安装（或标记为手动处理） |
| 对应工具的配置文件 | ✅ 已包含 delivery-flow 引用 |

完成后，在你的 AI 工具中说"我该做什么"即可开始使用 delivery-flow。
