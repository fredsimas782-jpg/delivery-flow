# 报价单

> 用途：售前向客户提交的正式报价，是签约与合同范围的基础依据。
> 原则：报价范围必须与方案一致，超出方案的项显式标注"需另行报价"；商机编号是 Trace 根，头部必填；支持多轮报价（日期后缀，不覆盖旧版）。

## 8. 自检清单

- [ ] 商机编号（Trace 根）是否已填写，且与商机档案一致？
- [ ] 报价范围是否与方案的合同范围意向一致？超出项是否标注"需另行报价"？
- [ ] 金额、工期、付款方式是否完整？
- [ ] 假设与除外项是否写清（供下游立项包关键约束引用）？
- [ ] 多轮报价是否用新日期后缀、未覆盖旧版？
