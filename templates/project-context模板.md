# 项目上下文（AI Agent 必读规则）—— 通用模板

> 这是 delivery-flow 的**实例层**占位模板。把它复制到消费方项目根，重命名为 `project-context.md`，逐节填成你项目的真实约束。
> 只写 **LLM 容易忽略、违反会返工/侵权/触碰红线的不显然约束**，不写常识。
> **换项目只换这一份文件，delivery-flow 模块本体保持通用、零项目内容。**
>
> 提示：也可以不用本模板，直接跑 BMAD `bmad-generate-project-context` 交互生成。
> 面向人读的项目治理文档（一句话项目/预算模块边界/RACI 式团队规则）另见 `项目宪法模板.md`；本文件面向 AI Agent 注入。
>
> **占位符约定**：本项目上下文模板使用 `{{mustache}}` 语法，原因是它与 BMAD `bmad-generate-project-context` 生成器的占位符格式一致。其余 delivery-flow 模板统一使用 `<填写>` 格式以利人读。两类约定各有用途，不矛盾。
